# 디자인 가이드라인 (v1)

Classon 프론트엔드 전역에서 일관된 사용자 경험을 제공하기 위한 200개의 디자인 규칙입니다. 모든 신규/기존 페이지는 아래 규칙을 기본으로 적용하고, 예외가 필요한 경우 디자인 리뷰를 통해 승인 후 문서에 반영합니다.

## 1. 브랜드 아이덴티티
- 로고는 좌상단에 고정 배치하고 클릭 시 항상 대시보드로 이동한다.
- 브랜드 보라(#6C5CE7)·네이비(#1F2937)·민트(#10B981) 3색을 핵심 팔레트로 사용한다.
- 서비스명은 한 줄, 문장형 태그라인은 로고 하단에만 배치한다.
- 브랜드 보라는 CTA 및 강조에만 사용하며 본문 텍스트에는 금지한다.
- 파비콘·앱 아이콘은 로고 심볼 단일 버전으로 통일한다.

## 2. 레이아웃 구조
- 메인 레이아웃은 좌측 사이드바·상단 헤더·컨텐츠 영역 3분할을 기본으로 한다.
- 컨텐츠 최대 폭은 1280px, 좌우 마진 32px을 유지한다.
- 페이지 상단에는 제목·설명·주요 액션이 포함된 헤더 블록을 둔다.
- 스크롤 시 헤더는 자연스럽게 사라지되 그림자로 구분감을 준다.
- 헤더 아래 첫 카드까지의 간격은 24px로 고정한다.

## 3. 그리드 & 정렬
- 12컬럼 그리드를 기본으로 하며 카드 폭은 3·4·6·12컬럼 단위만 선택한다.
- 모바일에서는 4컬럼 그리드로 자동 전환한다.
- 카드 내부는 8px 베이스라인 그리드를 유지한다.
- 텍스트와 아이콘은 좌측 정렬을 기본으로 하고 중앙 정렬은 비주얼 블록에서만 사용한다.
- 컬럼 간 최소 간격은 16px 이상 확보한다.

## 4. 타이포그래피
- 기본 폰트는 Pretendard, 대체는 system-ui → Apple SD Gothic → sans-serif 순으로 지정한다.
- 본문은 14px, 카드 제목 15px, 페이지 제목 24px, 섹션 제목 18px를 사용한다.
- 행간은 본문 1.6, 제목 1.3, 데이터 텍스트 1.2를 유지한다.
- Bold는 700, SemiBold는 600만 사용하며 800 이상의 굵기는 금지한다.
- 영문 표기는 문장형 소문자, 숫자 뒤 단위를 한글로 표기한다.

## 5. 컬러 팔레트
- 중립 회색 단계는 #111827, #4B5563, #6B7280, #9CA3AF, #E5E7EB, #F3F4F6 다섯 단계로 제한한다.
- 오류는 #DC2626, 경고는 #F59E0B, 성공은 #059669, 정보는 #2563EB로 고정한다.
- 밝은 배경은 #FFFFFF, 대체 배경은 #F9FAFB까지만 허용한다.
- 텍스트 대비비율 4.5:1 이상을 모든 상태에서 확보한다.
- 컬러 토큰은 디자인/코드 양쪽에서 동일 명칭으로 관리한다.

## 6. 아이콘
- 24px 정사각형 라인 아이콘을 기본으로 하고 선 두께는 1.5px로 통일한다.
- Filled 아이콘은 활성 상태 표현에만 사용한다.
- 아이콘과 텍스트 간 간격은 제목 12px, 버튼 8px을 유지한다.
- 혼합 아이콘 세트 사용을 금지하고 단일 세트를 사용한다.
- 아이콘 에셋은 SVG로 관리하며 색상은 CSS로 제어한다.

## 7. 이미지 & 일러스트
- 사진 비율은 4:3을 기본으로 하고 모서리는 12px 라운드를 적용한다.
- 일러스트는 톤다운 보라·민트 조합과 라운드 형태로 통일한다.
- 복잡한 배경 이미지는 40% 어둡게 처리한다.
- 실사 이미지는 흑백 변환 후 브랜드 색 포인트만 남긴다.
- 썸네일이 없을 경우 표준 플레이스홀더를 사용한다.

## 8. 버튼 스타일
- Primary 버튼은 보라 배경·흰 글자, Hover 시 8% 어둡게 한다.
- Secondary(Outline) 버튼은 보라 테두리·보라 텍스트·투명 배경을 기본으로 한다.
- Tertiary(Soft) 버튼은 보라 서피스(#EEF2FF) 배경과 보라 텍스트를 사용한다.
- 버튼 높이는 기본 40px, 작은 버튼 32px, 큰 버튼 48px으로 제한한다.
- 아이콘 버튼은 40px 정사각형, 라운드 12px, 홀버 시 배경을 노출한다.

## 9. 폼 요소
- 입력 필드는 높이 40px, 라운드 10px, 내부 패딩 12px로 통일한다.
- 포커스 링은 2px 보라색 외곽선과 내부 그림자 2px을 함께 사용한다.
- 레이블은 13px 회색 600, 필수 항목은 레이블 우측에 빨간 별표를 붙인다.
- Placeholder는 회색 400, 입력 완료 시 감춘다.
- 비활성 상태는 배경 #F3F4F6, 텍스트 #9CA3AF로 표현한다.

## 10. 검증 & 피드백
- 실시간 검증 메시지는 필드 하단 12px 빨간 텍스트로 표기한다.
- 성공 메시지는 초록 문구 대신 체크 아이콘을 동반한다.
- 서버 오류는 필드별 메시지와 상단 글로벌 요약을 동시에 제공한다.
- 저장 성공 시 토스트, 실패 시 모달/토스트를 구분한다.
- 검증 문구는 존댓말 문장형으로 작성한다.

## 11. 카드 & 컨테이너
- 카드 배경은 #FFFFFF, 라운드 12px, 그림자는 `0 1px 2px rgba(15,23,42,0.08)`을 사용한다.
- 카드 헤더와 본문 사이에는 #E5E7EB 1px 구분선을 둔다.
- 내부 여백은 상하 20px, 좌우 24px를 기본으로 한다.
- 카드 제목 아래 설명 텍스트는 13px 회색 500으로 제한한다.
- 액션 영역 버튼은 우측 정렬, 간격 8px을 유지한다.

## 12. 테이블 & 데이터
- 헤더는 회색 배경 #F9FAFB, Bold 13px, 가운데 정렬을 기본으로 한다.
- 본문 행 높이는 최소 48px, Hover 시 배경 #F3F4F6으로 표시한다.
- 선택된 행은 왼쪽 3px 보라 바와 배경 #EEF2FF를 동시에 적용한다.
- 수치형 데이터는 우측 정렬, 텍스트는 좌측 정렬한다.
- 테이블 하단에는 총 건수 혹은 페이징 정보를 명시한다.

## 13. 네비게이션 & 사이드바
- 사이드바 폭은 264px 고정, 접기 기능은 제공하지 않는다.
- 활성 메뉴는 배경 #EEF2FF, 텍스트·아이콘 보라색으로 표시한다.
- 아이콘과 텍스트 간 간격은 12px, 섹션 헤더는 12px 대문자로 표기한다.
- 서브 메뉴는 아코디언 형태로 확장하며 애니메이션은 150ms로 제한한다.
- 로그아웃 버튼은 하단 고정, 강조하지 않는다.

## 14. 헤더 & 상단 바
- 상단 바 높이는 64px, 하단 1px 경계선으로 구분한다.
- 우측에는 알림·프로필·빠른 액션을 순서대로 배치한다.
- 전역 검색·필터는 헤더 하단 별도 영역에 둔다.
- 모바일에서는 헤더 높이를 56px로 줄이고 아이콘만 노출한다.
- 헤더 버튼은 Outline 스타일을 기본으로 사용한다.

## 15. 브레드크럼 & 페이지 타이틀
- 브레드크럼은 페이지 제목 위 12px, 회색 400 텍스트로 배치한다.
- 현재 위치는 Bold 없이 보라 텍스트로 강조한다.
- 페이지 제목은 24px Bold, 오른쪽에 주요 버튼을 배치한다.
- 브레드크럼 구분자는 슬래시(/)를 사용한다.
- 클릭 시 한 단계씩만 이동하도록 제한한다.

## 16. 탭 & 분할 컨트롤
- 탭 높이는 40px, 활성 탭은 2px 보라 언더라인을 사용한다.
- 탭 간 간격은 24px, 텍스트는 14px SemiBold를 사용한다.
- 모바일에서는 탭을 좌우 스크롤 가능하게 전환한다.
- 아이콘 탭은 비활성 회색 400, 활성 시 보라색으로 채운다.
- 탭 콘텐츠 전환은 120ms 페이드 애니메이션을 적용한다.

## 17. 필터 & 검색
- 검색 바 최대 폭은 320px, 아이콘은 좌측 16px 위치에 고정한다.
- 필터 태그는 라운드 999px, 배경 #EEF2FF, 텍스트 보라색을 사용한다.
- 적용된 필터 수를 배지로 표시하며 최대 99+로 제한한다.
- 고급 필터는 슬라이드오버 패널로 통일한다.
- 패널 닫기 시 즉시 변경사항을 적용한다.

## 18. 페이지네이션
- 페이지네이션은 테이블 우측 하단, 12px 텍스트로 배치한다.
- 현재 페이지 버튼은 보라 배경과 둥근 테두리를 사용한다.
- 이전/다음 버튼은 아이콘+텍스트 조합, 비활성 시 회색 300을 사용한다.
- “전체 보기” 옵션은 100개 이상일 때 비활성화한다.
- 무한 스크롤은 카드 피드에서만 허용한다.

## 19. 모달 & 다이얼로그
- 기본 폭은 480px, Large는 720px으로 제한한다.
- 헤더·본문·푸터 섹션을 명확히 구분하고 스크롤은 본문에만 허용한다.
- 배경은 rgba(17,24,39,0.48)로 어둡게 처리한다.
- 닫기 버튼은 우상단 24px 아이콘으로 Tab 순서에 포함한다.
- 위험 작업은 붉은 CTA와 추가 확인 문구를 함께 표기한다.

## 20. 토스트 & 알림
- 토스트는 우상단에서 쌓이며 최대 3개까지만 동시에 표시한다.
- 기본 높이는 56px, 아이콘+제목+본문 구조를 유지한다.
- 성공 초록, 오류 빨강, 정보 보라, 경고 주황 배경을 사용한다.
- 자동 닫힘은 4초, 마우스 오버 시 일시 중지한다.
- 알림 배지는 8px 빨간 점으로 표현한다.

## 21. 빈 상태
- 48px 일러스트+제목+설명+보조 버튼 구성으로 통일한다.
- 설명 문구는 14px, 최대 두 줄로 제한한다.
- Primary CTA 대신 Outline 버튼을 기본으로 사용한다.
- 반복 빈 상태에는 도움말 링크를 함께 제공한다.
- 긍정적 어조를 유지하고 부정 표현을 피한다.

## 22. 로딩 상태
- 스피너 대신 스켈레톤을 우선 적용한다.
- 스켈레톤 라운드는 실제 컴포넌트와 동일하게 맞춘다.
- 전체 페이지 로딩 시 인터랙션을 막지 않도록 한다.
- 지연이 1초 이상이면 “불러오는 중…” 문구를 추가한다.
- 긴 로딩은 예상 시간을 텍스트로 안내한다.

## 23. 에러 처리
- 페이지 오류는 일러스트+설명+재시도 버튼으로 구성한다.
- 부분 컴포넌트 오류는 카드 내부 경고 배너로 표시한다.
- API 오류 메시지는 사용자 친화 문장으로 변환한다.
- 반복 오류 시 고객센터 링크를 제공한다.
- 404 페이지는 대시보드로 이동하는 CTA만 노출한다.

## 24. 접근성
- 모든 인터랙션은 키보드(Tab, Enter, Space)로 조작 가능해야 한다.
- 포커스 링은 시스템 스타일을 숨기지 않고 커스텀 링을 추가한다.
- 버튼·링크는 ARIA role과 레이블을 명확히 지정한다.
- 모달 열림 시 배경 접근을 차단하고 닫힌 후 포커스를 복귀시킨다.
- 색상 정보에만 의존하지 않고 텍스트·아이콘을 병행한다.

## 25. 반응형 동작
- 데스크톱 ≥1024px, 태블릿 768–1023px, 모바일 ≤767px 구간을 따른다.
- 사이드바는 태블릿에서 상단 드로어로 전환한다.
- 카드 3열은 태블릿 2열, 모바일 1열로 재배치한다.
- 표는 모바일에서 카드 리스트로 변환한다.
- 그래프는 모바일에서 가로 스크롤 영역으로 감싼다.

## 26. 브레이크포인트
- xs 0–479, sm 480–767, md 768–1023, lg 1024–1439, xl 1440+ 구간을 정의한다.
- 미디어쿼리는 최소 폭 기준으로 작성한다.
- md 이하에서는 그리드 갭을 16px로 축소한다.
- md 이하에서는 글자 크기를 한 단계씩 줄인다.
- sm 이하에서는 헤더 버튼 텍스트를 감추고 아이콘만 남긴다.

## 27. 간격 스케일
- 기본 스페이싱 단위는 4px이며 8·12·16·24·32px 단위만 사용한다.
- 카드 간격 24px, 섹션 간격 32px, 폼 필드 간격 16px을 유지한다.
- 리스트 아이템 간격은 12px, 아이콘+텍스트 간격은 8px으로 한다.
- 상단/하단 패딩은 좌우보다 4px 크게 설정한다.
- 페이지 하단 여백은 최소 48px 확보한다.

## 28. 그림자 & 깊이
- Elevation 단계는 3단계(낮음, 중간, 높음)만 사용한다.
- Hover 시 Elevation을 한 단계만 높인다.
- 모달과 드로어는 항상 최고 단계 Elevation을 유지한다.
- 토글·드롭다운 패널은 중간 Elevation을 사용한다.
- 그림자 색상은 rgba(15,23,42,x) 계열만 허용한다.

## 29. 모션 & 애니메이션
- 전환 시간은 120–200ms, 이징은 `cubic-bezier(0.4, 0, 0.2, 1)`을 사용한다.
- 슬라이드 진입은 16px 이동과 페이드를 조합한다.
- 로딩 반복 애니메이션은 1.2초 주기로 제한한다.
- 탭·모달 전환에는 스프링 효과를 사용하지 않는다.
- 자동 재생 모션은 3초 이상 지속하지 않는다.

## 30. 마이크로 인터랙션
- 버튼 클릭 시 5% 어두운 프레스 상태를 100ms 적용한다.
- 체크박스·스위치는 색상 전환만 사용하고 스케일 애니메이션을 지양한다.
- 성공 액션에는 체크 아이콘과 짧은 페이드를 제공한다.
- 드롭다운 열림은 하단 8px 슬라이드를 적용한다.
- 입력 포커스는 경계선 색이 120ms 안에 전환되도록 한다.

## 31. 콘텐츠 톤 & 언어
- 모든 문구는 존댓말, 명령형 대신 안내형 표현을 사용한다.
- 경고 문구는 “~해주세요” 대신 “~해야 합니다”로 명확히 한다.
- 시간 표기는 24시간제, 날짜는 YYYY.MM.DD 형식을 사용한다.
- 숫자 뒤 단위는 띄어 쓰고 한글로 표기한다.
- 문장은 60자 이내, 최대 2문장으로 구성한다.

## 32. 데이터 시각화
- 색상 대비를 고려해 6색 이하 팔레트를 사용한다.
- 그래프 제목은 16px, 범례는 13px, 축 라벨은 12px로 표기한다.
- 도넛 그래프 중앙에 핵심 수치와 증감 배지를 함께 표기한다.
- 라인 그래프 Hover 시 포인트 강조와 툴팁을 제공한다.
- 대시보드 그래프는 동일한 y축 단위를 유지한다.

## 33. 캘린더 & 일정
- 달력 헤더에 월/연도를 명확히 표기하고 좌우 네비게이션을 제공한다.
- 출결 표시는 출석/결석/미처리 3색 배지로 구분한다.
- 일정 팝오버는 폭 320px, 핵심 필드를 카드 형태로 노출한다.
- 주말은 연한 회색으로 표시하되 가독성을 유지한다.
- 드래그 이동 시 그림자와 0.6 투명도를 적용한다.

## 34. 출결 전용
- 출결 상태 배지는 카드·테이블 모두 동일 색 체계를 사용한다.
- 출석 카드 헤더는 학생 이름·수업명·시간 순으로 배치한다.
- 미처리 학생 목록은 칩 형태, 최대 3명 + more 형태로 표기한다.
- 모바일에서는 탭을 상단 고정해 전환을 돕는다.
- 출결 사유 입력은 80자 제한과 남은 글자 수를 제공한다.

## 35. 수업 관리 화면
- 수업 목록 기본은 카드형, 테이블 전환 옵션을 함께 제공한다.
- 핵심 통계를 카드 상단에 배치한다.
- 상세 탭 순서는 “개요 → 출결 → 자료 → 기타”로 고정한다.
- 교사·학생 프로필 이미지는 동일 원형 썸네일을 사용한다.
- 수업 메모는 회색 노트 카드 스타일로 통일한다.

## 36. 학생 관리 화면
- 학생 검색 바를 상단 고정하고 결과는 카드 리스트로 보여준다.
- 학생 상세는 좌측 요약 카드, 우측 탭형 상세 컨텐츠를 사용한다.
- 출결 이력은 그래프와 리스트의 2단 구조를 유지한다.
- 상담 기록은 시간 역순, 강조 색상 최소화로 표시한다.
- 위험 경고는 빨간 배너 대신 중립 배경+아이콘 조합을 사용한다.

## 37. 마케팅 화면
- 생성/미리보기 화면은 가변 폭 960px으로 확대한다.
- 미리보기는 실제 발송 디자인과 1:1 비율로 보여준다.
- 스텝 바는 상단 고정, 단계 수를 숫자로 명시한다.
- 템플릿 썸네일은 3열 그리드, Hover 시 확대 효과를 적용한다.
- CTA는 Secondary 버튼을 기본으로 사용한다.

## 38. 개발/관리 도구
- 위험 기능은 붉은 배경 카드와 경고 아이콘을 함께 사용한다.
- 확인 모달에 두 번의 확인 문구를 포함한다.
- 테스트 데이터 삭제는 체크박스와 텍스트 입력 확인을 요구한다.
- 개발 툴에는 “실 환경에 영향 없음” 문구를 상단에 표기한다.
- 관리자 기능은 기본 숨김 상태에서 토글로 노출한다.

## 39. 문서 & 핸드오프
- 디자인 규칙은 Notion·Figma·코드베이스 3곳에 동기화한다.
- 컴포넌트 변경 시 Storybook 문서도 함께 갱신한다.
- 각 규칙에는 예시 화면 링크 또는 캡처를 첨부한다.
- 변경 이력은 YYYY-MM-DD 형식으로 기록한다.
- 디자인 토큰은 단일 JSON 소스에서 파생한다.

## 40. QA & 거버넌스
